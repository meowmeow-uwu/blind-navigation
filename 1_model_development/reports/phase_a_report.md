# Phase A Evaluation Report

- **Date**: 2026-11-07
- **Baseline Git Commit**: see `weights/phase_a_frozen_manifest.json`
- **Dataset taxonomy**: ROD-Dataset (25 classes; 11 shared with COCO, 14 domain-only)

> ## ⚠️ Data caveat
> `datasets/processed/rod_v1/` currently contains an **11-image synthetic placeholder** (generated by `scripts/_generate_sample_rod.py` from `assets/smoke_test.jpg` with hand-written boxes). The real ROD dataset (24,326 images) has **not been downloaded**.
> All accuracy numbers below are **pipeline smoke results only**. They are not evidence of model quality and must not be used for model selection.
